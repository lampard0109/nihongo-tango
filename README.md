# 大家的日语 单词帐（个人学习用）

《みんなの日本語 初級I・II》第1〜50课单词帐，离线网页版。打开 `index.html` 即可使用。

## 用 GitHub Pages 发布

1. 在 GitHub 新建仓库（例如 `nihongo-tango`）。
2. 把本文件夹里的 `index.html` 和 `.nojekyll` 上传到仓库根目录（网页上点 Add file → Upload files 即可）。
3. 仓库 Settings → Pages → Build and deployment：Source 选 `Deploy from a branch`，Branch 选 `main`、文件夹选 `/ (root)`，保存。
4. 1〜2分钟后，网址为 `https://<你的用户名>.github.io/nihongo-tango/`。

## 更新

只替换 `index.html` 再提交即可。网址不变，学习进度会保留（进度保存在手机浏览器里，不在仓库里）。

## 注意

- 免费账号的 GitHub Pages 需要公开仓库，仓库内容任何人都能看到。本单词帐仅供个人学习，请勿宣传链接。
- 网页已设置 noindex，正常情况下不会被搜索引擎收录。
